# 🌱 TRUEKIT - El Cambio Justo

**Conecta, Transforma, Intercambia**

Una plataforma digital para el intercambio sostenible de objetos y servicios que impulsa la economía circular en tu comunidad.

---

## 📋 Descripción del Proyecto

TRUEKIT es una aplicación web desarrollada como proyecto educativo por estudiantes de 1º SMR del IES Hermanos Machado (curso 25/26). La plataforma promueve:

- ✅ Economía circular y reutilización
- 🤝 Conexiones comunitarias significativas
- 🌍 Sostenibilidad y respeto al medio ambiente
- 💚 Colaboraciones locales con impacto social

---

## 🚀 Características Principales

### Sistema de TrueTokens
- Compensación inteligente entre objetos de diferentes valores
- Sistema sin especulación con límites establecidos
- Flujo constante que incentiva intercambios continuos

### Servicios en Campaña
- Acceso a experiencias únicas
- Clases, talleres, diseño gráfico, reparaciones
- Ofertas por tiempo limitado

### Comunidad y Confianza
- Sistema de reseñas y valoraciones
- Insignias por intercambios y acciones éticas
- Niveles de usuario con servicios exclusivos

### Colaboraciones Locales
- **BIO-Montequinto Alverde**: Inserción sociolaboral
- **Comercio Local**: Visibilidad para negocios
- **Planta un Árbol**: Reforestación en Dos Hermanas

### Movilidad Sostenible
- Bonificación por uso de transporte público
- Reducción de huella de carbono

---

## 💻 Tecnologías Utilizadas

- **HTML5**: Estructura semántica y accesible
- **CSS3**: Diseño responsivo con variables CSS y animaciones
- **JavaScript (Vanilla)**: Interactividad y funcionalidad dinámica
- **Google Fonts**: Tipografías Fredoka y DM Sans
